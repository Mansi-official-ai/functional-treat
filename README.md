Data Analyzer and Transformer Program

Description

This Python program is a menu-driven Data Analyzer and Transformer Program. It allows the user to enter numbers and perform different operations such as displaying data, calculating factorials, filtering data, sorting numbers, and displaying statistics.

Features

Input Data

Accepts numbers separated by spaces.

Display Data Summary

Displays the entered data.

Shows total number of elements.

Displays minimum and maximum values.

Calculates the sum and average.

Calculate Factorial

Takes a number from the user.

Calculates and displays its factorial.

Filter Data by Threshold

Takes a threshold value.

Displays numbers greater than the given threshold.

Sort Data

Allows sorting in:

Ascending order

Descending order

Display Dataset Statistics

Displays useful statistics about the entered dataset.

Exit Program

Safely exits the program.

Enter numbers separated by space: 34 12 56 78 43 21 98

Conclusion

The Data Analyzer and Transformer Program provides a simple way to analyze and transform numerical data using a menu-driven Python program. It demonstrates important Python concepts such as lists, loops, conditional statements, functions, sorting, filtering, factorial calculation, and basic data analysis.
